# 守夜人｜智慧社区·智慧养老互动科普 H5

> 爸妈睡下后，谁来守这盏灯？

面向社区居民（尤其 60 岁以上老人与子女）的互动科普 H5。用一次 3 分钟的“夜间守护”实验，讲清智慧养老中技术能做什么、不能做什么，以及人应该在什么时候接手。

## 立即访问

**本机演示链接：<http://127.0.0.1:62180/>**

需保持本机静态服务运行：

```powershell
python -m http.server 62180 --bind 127.0.0.1
```

如需公网发布，将整个文件夹上传到任意静态托管，保持 `index.html`、`styles.css`、`app.js`、`favicon.svg` 的相对路径不变。

## 体验主线

1. 凌晨 2:37，毫米波雷达发出“疑似跌倒”告警。
2. 做三次判断：先验证 / 会联动 / 不盲动。
3. 查看守夜报告，生成一张可保存、可转发的家庭守夜卡。
4. 继续探索 24 小时时间轴、设备边界、隐私开关与四条识伪卡。
